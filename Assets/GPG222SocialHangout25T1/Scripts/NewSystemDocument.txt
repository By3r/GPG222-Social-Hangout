Game Flow:
1. Server starts up
2. Player connects to server
3. Player enters a username and chooses a duck
4. Player joins the lobby
{
	Server creates the PlayerData for the player that just joined the lobby
	Server adds this PlayerData to a list of players in the lobby
}
5. Lobby creates the pllayer's chosen duck
6. New player connects to server
7. New player enters username and chosen duck
8. New player joins the lobby 
{
	Server adds the new player's PlayerData to the list of players in the lobby
	Server sends the list of PlayerDatas to all players in the lobby
	Each player's lobby spawns the new player's duck
}

PlayerData 
{
	public int DuckID // This will be the owner ID for synced objects, the player's color
	public string Username
}
